**SteamArena** adalah platform gamifikasi evaluasi proyek inovasi multidisiplin, leaderboard hackathon nasional, dan matriks radar interaktif 5-sumbu (**Science**, **Technology**, **Engineering**, **Art & Design**, **Mathematics**) untuk mahasiswa dan peneliti.

## 🌟 Fitur Utama

1. **Matriks Radar Interaktif 5-Sumbu (STEAM Pentagonal Radar)**:
   - Visualisasi poligon dinamis yang merespons kalkulasi agregat skor STEAM secara real-time.
   - Evaluasi menyeluruh meliputi: *Scientific Rigor*, *Technological Feasibility*, *Engineering Architecture*, *Art & UX Aesthetics*, dan *Mathematical Formulations*.

2. **Gamified Peer-Review & Voting Engine**:
   - Sistem rubrik juri terstruktur dengan bobot desimal otomatis dan pencegahan manipulasi suara.
   - Komentar kualitatif juri dan lencana penghargaan (*Grand Champion Nominee*, *Best Mathematical Model*, *High Performance Engine*, *Best Visual & Aesthetic*).

3. **Leaderboard Real-Time & Kategori Lintas Bidang (Tracks)**:
   - Pemeringkatan transparan berdasarkan skor komposit STEAM tertimbang.
   - Filter lintas rumpun ilmu: *AI & Research*, *Simulasi & Fisika*, *Geospasial & Iklim*, *3D & Komputasi Parametrik*, serta *Smart IoT Edge*.

## 🚀 Menjalankan Secara Lokal

```bash
# Clone repositori
git clone https://github.com/nazaa-arch/steam-arena.git
cd steam-arena

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```

Buka browser di `http://localhost:3005`.

## 📦 Build Produksi

```bash
npm run build
```

Hasil build tersimpan dalam folder `dist/` dan siap dipasang ke server produksi.
